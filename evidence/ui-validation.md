# Chainlit 集成验收

日期：2026-10-16，Asia/Shanghai。版本：Chainlit 2.12.0。界面与 API 为两个真实本机进程，API 使用 SQLite 与 offline 工程夹具，所有输入和账号均为合成测试值。

## 已实际操作

| 操作 | 观察结果 |
|---|---|
| 登录 | 应用身份与对应应用令牌可登录，用户资料不带令牌 |
| 同意并开始 | 点击后创建后端会话，显示摘要和删除入口 |
| 输入“最近睡不好” | 显示工作流 Step、追问与带原文的候选事实 |
| 确认前查看摘要 | 本次困扰为“未提供” |
| 点击确认后查看摘要 | 本次困扰为“最近睡不好”，出现撤回按钮 |
| 撤回主要困扰 | 显示撤回成功，后端快照更新 |
| 问“什么是四诊？” | 展示解释、来源定位和版本 |
| 二次确认删除 | API 删除成功，当前页面旧输入、回复、候选、摘要和引用均被清除，恢复同意入口 |
| 图片语法原文 | 合成 Markdown 图片语法显示为文字，DOM 中没有生成对应外部图片节点 |

对话页面检查了 1440×1000 桌面与 390×844 手机宽度的明暗主题，中文正文、引用与操作可读，没有观察到横向溢出。登录与删除完成状态另在手机宽度检查。项目沿用 Chainlit 原生组件与主题，没有自定义前端组件或 CSS。

预览：[桌面](../docs/images/chainlit.png)、[手机](../docs/images/chainlit-mobile.png)。附加明暗主题截图留在本地临时目录，不作为发布资产。

## 自动检查

`tests/test_ui_client.py` 的 6 个用例覆盖同请求重试、两种截断流、错误体脱敏、明确版本拒绝，以及真实 API/SQLite 的完整就诊生命周期与跨身份隔离。核心后端原有的并发、取消、租约与幂等测试继续执行。

## 边界与未执行项

- 没有配置真实模型平台；界面不证明任何第三方供应商协议已经连通。
- 网络失败恢复与版本拒绝有自动协议测试；未用浏览器网络故障注入逐项验证，不能声称全部故障场景均已人工点击验收。
- 没有运行 Lighthouse 评分、专业无障碍审计或公网性能压测；这里记录功能与可读性检查，不作这些认证。
- 没有配置 Chainlit 数据层；刷新不会恢复会话，API 记录仍需按说明主动删除。供应商留存由供应商策略决定。
- 浏览器操作使用合成资料，不涉及真实患者数据。没有将测试令牌或登录密码放入截图。

## 源码复核

复核了 API 与 UI 身份一致性、按钮原文和来源匹配、未决请求复用、明确版本拒绝后刷新、只显示已提交响应、错误消息去敏、删除清屏，以及源码包不包含配置秘密和 PDF。人工界面验收和自动合同测试的范围分别列出，未以截图替代并发与存储测试。
