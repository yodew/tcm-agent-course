# 临床研究知识包采集验收

日期：2026-10-18。此报告验证来源固定、整理投影和软件合同，不是临床有效性报告。

## 来源与产物

- TCMEval-SDT train：实际下载并投影 200 条；固定提交、原文件与许可声明 SHA256 记录在 inputs/receipts。
- MTCMB TCM-Diagnosis：实际下载并投影 200 条，仅输出短标签；未将仓库代码许可当作数据许可。
- 问诊条目 63 个；术语 845 个；描述性关联 769 条；候选资料卡 294 张；历史文献参考卡 3 张。
- 稀疏性：267 张单记录卡，40 张无保留观察卡。所有描述性关联均不作为诊断权重，空卡不表示满足了全部条件。
- 未导出原始病例、原题、病机推理、处方、用量或个案身份字段。未使用 TCMEval test/validation 构建知识。
- 1014 个低频、过长或不符合保守导出策略的观察标签未导出；筛选不是临床判断或匿名保证。

## 验证边界

来源引用与条目 ID、关联类型、资料卡引用、问题前置依赖及环、观察未知状态与时区由实际代码校验。资料卡 clinical_use 固定 disabled，未知必要条件保持 null，不将病例共现当成临床诊断条件。

已运行知识包审计、问题队列预览、研究术语检索和 JSON Schema 导出。16 项新自动化测试覆盖否定保留、记录内去重、短标签投影、敏感/稀有标签过滤、来源失效、依赖环、越权启用临床推断及未知/未测数据合同。当前完整套件 104 passed / 2 skipped；结果以 tests.txt 为准。

未执行临床专家审核、独立病例诊断验证、实际面舌脉 API 映射或真实模型诊断。本包当前与运行服务的教学知识隔离；面舌脉接口样本到达后再实现具体适配。
