# Chainlit 界面约定

使用 Chainlit 原生聊天、Step、Action 和 Text 组件，沿用其明暗主题、字体、间距、焦点和响应式布局，不引入自定义 CSS 或独立前端依赖。

页面为登录、数据使用确认、对话三种状态。主要操作使用中文文字标签；执行过程使用可折叠 Step；候选事实、已确认事实和来源分别展示。每个候选事实单独确认，已确认事实可撤回后重述。输入尚未得到确定结果时，保留同一请求重试，避免重复写入。

界面显示实际工作流事件，不显示模型内部推理。引用使用原生文本附件，用户事实和摘要直接以消息展示，不生成文件附件；消息转义 Markdown 控制符。供应商密钥、应用令牌和认证头不放进浏览器消息、Action payload、用户 metadata 或日志。

会话先明确同意才创建。删除操作另有确认；成功后移除当前页面的健康信息消息。未配置 Chainlit 持久化，刷新页面会建立新的界面会话，不自动恢复旧会话；需在刷新前查看摘要或删除当前记录。
